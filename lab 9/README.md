## Objective
Apply morphological image processing techniques (erosion, dilation, opening and closing) to a binary image, and investigate how the shape and size of the structuring element affect the processed image.

## Tasks
- **Task 1:** Apply erosion, dilation, opening and closing to a new binary image (`Balls.png`) and display the original image with the result of each operation.
- **Task 2:** Apply erosion and dilation using different structuring element shapes (square, cross, ellipse) and kernel sizes (3×3, 5×5, 7×7), then compare the results.
